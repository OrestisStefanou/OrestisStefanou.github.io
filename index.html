InvestPal

open source · local-first

An AI investment analyst that runs on your own machine. Ask whether a company is worth owning and it does the work: pulls the financials, runs a written valuation procedure and checks the answer against what you already hold.

  • Fifteen written analysis procedures, from earnings quality to margin of safety, versioned in the open
  • Eight free public data sources: no paid vendor and no API keys
  • Remembers your goals, runs scheduled reviews, and can connect to Alpaca, Coinbase or Interactive Brokers, read-only if you prefer
  • Use it from Claude Code, Claude Desktop, any MCP client, a local web app or its REST API
Go · Python · TypeScript · MCP See InvestPal →

Loci

open source · Go

Agent conversations are per session and disposable. Loci keeps what they produce and files it by the work it belongs to, so the next session, or the next person, starts from what was already settled.

  • Captures every Claude Code session in a repository through hooks
  • Agents save decisions and their reasons as memories, attached to a project, a task and tags
  • Search by text or by meaning, with embeddings from a local model
  • One static binary, one database file per store, nothing leaves your machine
Go · Turso · Ollama · Claude Code hooks View on GitHub →
