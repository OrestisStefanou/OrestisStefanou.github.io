# orestisstefanou.github.io

Personal site of Orestis Stefanou: homepage, case studies, engineering posts and the InvestPal product page. Built by GitHub Pages with Jekyll.

| Path | What |
|---|---|
| `index.html` | Homepage |
| `_pages/software-factory.md` | Case study at `/software-factory/` |
| `_pages/writing.html` | Post archive at `/writing/` |
| `_pages/investpal.html` | InvestPal product page at `/investpal/` (standalone, own CSS and JS) |
| `_posts/` | Posts. `featured: true` puts a post on the homepage |
| `_layouts/` | `base`, `post`, `page`, `redirect` |
| `assets/css/site.css` | All site styles, light and dark |

Run locally with `bundle install && bundle exec jekyll serve`.
